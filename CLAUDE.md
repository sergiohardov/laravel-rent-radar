# laravel-rent-radar

Личный бот поиска квартиры в долгосрочную аренду в Одессе. Каждые 5–10 минут опрашивает площадки объявлений, отбирает подходящие по фильтрам и сектору, обогащает их через LLM и шлёт карточки в Telegram-группу. Инструмент только для себя: один пользователь, одна группа, без мультиюзерности. Общение с владельцем проекта — на русском.

## Начало каждой сессии

1. Прочитай «Текущую позицию» в [docs/LOG.md](docs/LOG.md).
2. Сверься с [docs/ROADMAP.md](docs/ROADMAP.md): этап и следующий пункт.
3. Проверь `git status` и `git branch --show-current`: ветка должна совпадать с «Текущей позицией».
4. Коротко напомни, где остановились, и продолжи с того же шага, если пользователь не попросил другое.

## Режим работы

- **Claude делает сам, пошагово по ROADMAP.** Один пункт ROADMAP — одна ветка и один PR: код, тесты, документация, push. Крупный пункт можно разбить на несколько веток, сказав об этом в плане.
- Перед пунктом — короткий план: что делаем, какие файлы меняются, какие будут коммиты. Что нужно от пользователя (ключи, аккаунты, значения настроек) — спросить до начала.
- Команды (`docker`, `composer`, `artisan`, `npm`, тесты) запускает Claude.
- После пункта — остановка: что сделано, как проверить у себя, что требует решения пользователя. Следующий пункт — после сообщения пользователя о `pull` (см. Git).
- Есть несколько подходов — коротко варианты с плюсами и минусами и какой выбран. Решения, меняющие «Стек и решения», принимает пользователь.
- Объяснения короткие и по делу. В чате при правках — только изменённые фрагменты.

## Git

Работаем по скиллу `git-workflow`.

1. Claude создаёт ветку от свежего `main`: `<тип>/NN-slug`, где `NN` — номер пункта ROADMAP (`chore/05-dockerfile`, `feature/13-lun-adapter`).
2. Claude коммитит атомарно после проверки (тесты, покрывающие изменение, зелёные или пользователь подтвердил результат) и пушит ветку. Сообщения — Conventional Commits на английском.
3. Пользователь на GitHub открывает PR и мержит в `main`, затем делает `pull` в локальный `main` и пишет об этом в чат. PR и merge — зона пользователя, `gh` не установлен.
4. Следующая ветка создаётся только от `main` после сообщения о `pull`.

Единственный прямой коммит в `main` — первый коммит репозитория.

## Лог и передача между сессиями

Источник правды — файлы репозитория, а не память Claude.

- После каждого завершённого шага обнови «Текущую позицию» в `docs/LOG.md`: этап, пункт, ветка, следующее действие, открытые вопросы.
- Значимые события (пункт закрыт, решение принято или изменено, проблема решена) — в «Хронологию»: новые сверху, формат `YYYY-MM-DD — что сделано`.
- Пункт ROADMAP закрыт — отметь `[x]`.
- Документация (`LOG`, `ROADMAP`, `README`) обновляется в той же ветке, что и пункт. Изменился запуск, структура или стек — обнови `README.md`.
- Контекст подходит к лимиту — напиши подробный handoff в «Текущую позицию».

## Стек и решения

Результаты grill-сессии 2026-10-03. Меняются только по решению пользователя, каждое изменение — запись в хронологию LOG.

**Стек:** Laravel 13 · Filament 5 · PostgreSQL · PHP 8.4 · Pest · Nutgram · `anthropic-ai/sdk` · Node 24 LTS (только сборка ассетов).

### Прод: shared-хостинг nic.ua (NIC-S, cPanel, CloudLinux)

Хостинг задаёт рамки для кода:

- LiteSpeed (понимает `.htaccess` как Apache), Docker на проде нет. Проверенные факты о хостинге — в [docs/hosting.md](docs/hosting.md).
- `memory_limit` 128M, `max_execution_time` 60 с, процессы под лимитами LVE. Объявления обрабатываются потоком, по одному. Один запуск источника укладывается в ~60 с.
- Только короткоживущие процессы: cron раз в минуту вызывает `schedule:run`, очередь разбирается через `queue:work --stop-when-empty` из scheduler.
- Источники читаются обычным HTTP/JSON (headless-браузера на хостинге нет).
- IP общий и зарубежный (сеть Hetzner, Финляндия). ЛУН и OLX с него отвечают 403, поэтому на проде они ходят через украинский прокси дата-центра: адрес — в `.env`, у источника флаг «через прокси». DIM.RIA — напрямую. В dev прокси не нужен.
- Поддомен с SSL: на нём Filament и Telegram webhook.
- Деплой — GitHub Actions: тесты → `composer install --no-dev -o` → сборка ассетов → rsync → `artisan migrate --force && artisan optimize`. Composer и npm работают только в CI.
- В cron и деплой-скрипте PHP вызывается по полному пути выбранной версии (вида `/opt/alt/php84/usr/bin/php`): системный `php` на CloudLinux может оказаться другой версии.

### Dev повторяет прод

Своё Docker-окружение со своим compose, без Sail и Herd:

- `php:8.4-apache` + `mod_rewrite`, расширения `pdo_pgsql intl zip bcmath`, php.ini с лимитами прода.
- Scheduler — supercronic с `schedule:run` раз в минуту, как cron на хостинге.
- Node — одноразовый контейнер для сборки.
- `cloudflared` — публичный HTTPS для webhook dev-бота.
- Postgres `16` до проверки версии на хостинге, отдельная тестовая БД.

### Источники v1

- **ЛУН** — агрегатор ~24 сайтов, аренда живёт на flatfy.ua.
- **OLX** — напрямую через публичный JSON API сайта. CloudFront пускает по сочетанию TLS-отпечатка клиента и версии HTTP, версия задаётся `SOURCES_HTTP_VERSION` (PHP на OpenSSL — HTTP/2). Otodim не используем. См. [docs/sources/olx.md](docs/sources/olx.md).
- **DIM.RIA** — внутренние эндпоинты dom.ria.com без ключа: поиск id + карточка по id. Официальный API платный, это запасной путь. См. [docs/sources/dimria.md](docs/sources/dimria.md).
- Опрос раз в 5–10 минут с джиттером. Telegram-каналы вне v1.

### Сектор

- Сектор — whitelist улиц и ЖК с алиасами (рус/укр, старое/новое название, сокращения) плюс районы. Наполняется вручную в админке и импортом из OpenStreetMap по точке и радиусу из Settings: карта нужна только для этого импорта.
- Координаты объявлений для сектора не используются. Проверяется только текст: заголовок, описание и адресные поля площадки (улица, ЖК, район).
- Совпала улица или ЖК — объявление в секторе. Совпал только район — проходит с 📍?. Не совпало ничего — отсев.
- У записи whitelist с числом в названии («54-я Жемчужина») это число должно быть в тексте объявления — модель путает номера ЖК одной серии. Длинная улица из whitelist пропускает и дома вне радиуса: номер дома не проверяется.

### Фильтры

- **Жёсткие:** комнаты, этаж, цена ≤ X грн. Цены в $ и € переводятся в гривну по курсу НБУ раз в сутки.
- **Евродвушка** (кухня-гостиная + спальня) считается двухкомнатной: площадки пишут её как 1 комнату. Когда «комнат от» = 2, однушка проверяется по этажу и цене, затем по тексту (`EuroTwoRoomDetector`: «евродвушка» в рус/укр написаниях или кухня-студия/гостиная с отдельной спальней) — совпало, проходит с флагом «евродвушка», нет — отсев до LLM. Переключатель в Settings.
- **Генератор:** нужен общий генератор дома на коммуникации (вода, тепло); свет в квартире не обязателен, резерв только для квартиры не считается. Явное «нет генератора», «вода не работает» или «тепло не работает» при отключениях — отсев; не сказано — проходит с ⚡❓.
- **Второй проход после LLM** (`hard_filter_text`): пустые поля площадки заполняются из текста, заполненные не перезаписываются; данные площадки о работе при отключениях (ЛУН `autonomy_*`, OLX `blackout_autonomy`) заполняют то, о чём текст молчит.
- Значение неизвестно — объявление проходит с ❓. У каждого фильтра переключатель «пропускать при ❓».
- **Мягкие флаги от LLM:** ⚡ генератор (что запитано и когда), 🔒 закрытая территория, 👤 собственник (✅/❌/❓), плюс 📍 чем подтверждён сектор (улица / ЖК / только район).

### Дубли

Отсекаются только по `source + external_id`, между сайтами не склеиваются. Первый запуск берёт только свежие объявления — сколько помещается в лимит страниц и времени запуска, около суток; старые не загружаются. Рассылка в группу — с троттлингом до 20 сообщений в минуту, фото альбома считаются по одному.

### LLM

- Haiku через `anthropic-ai/sdk` за интерфейсом `ListingEnricher`. Модель задаётся в `.env`. Качество и расход — `php artisan llm:eval` на размеченном наборе `tests/Fixtures/llm-eval/cases.json` (реальный API, ~$0.17 за прогон). ~$0.0054 за объявление; кэш промпта не срабатывает — у Haiku 4.5 минимум 4096 токенов, наш системный промпт ~2500.
- Вызывается только для объявлений, прошедших дешёвые фильтры.
- На вход — заголовок, описание и адресные поля площадки. На выход — JSON через tool use: `complex, street, house, district, floor, floors_total, rooms, area, price, currency, generator, generator_water, generator_heating, generator_elevator, generator_schedule, closed_territory, is_owner, location_id`.
- `generator_schedule` — enum: круглосуточно / днём / по графику / не сказано.
- Флаги `true / false / null`: `null` значит «в тексте не сказано», модель не угадывает. В ответе модели флаги — `yes / no / unknown`: строгая схема инструмента допускает не больше 16 nullable-полей и не принимает `enum` на nullable-типе.
- Ошибка LLM на одном объявлении (лимит, 5xx, таймаут, отказ) — объявление `failed` с причиной, запуск идёт дальше; неверный ключ или битый запрос роняют весь запуск.
- Whitelist сектора с id и алиасами передаётся в промпт (кэшируется вместе с системным промптом). Модель возвращает `location_id` совпавшей записи или `null`, код проверяет, что такой id есть в whitelist.

### Telegram

- Nutgram, webhook и в dev (Cloudflare Tunnel), и на проде.
- Отдельный dev-бот и тестовая группа, токены и `chat_id` в `.env`.
- **Карточка** на русском: альбом до 5 фото (подпись на первом; Telegram считает каждое фото сообщением в лимите группы), цена (оригинал + грн), комнаты/этаж/площадь, ЖК или адрес, 📍, флаги списком (генератор, вода, тепло, лифт, график, территория, собственник), площадка и ссылка. Кнопок нет.
- **График генератора** только показывается: круглосуточно или днём — ✅ (требование «хотя бы весь день»), по графику — ⚠️, не сказано — ❓.
- **Алерты** в ту же группу: 3 ошибки источника подряд или 24 часа без новых объявлений.

### Админка Filament

Один пользователь-админ. Разделы:

- **Settings:** точка и радиус (для импорта улиц), порог цены, комнаты, этажи, переключатели ❓.
- **Locations:** whitelist ЖК/улиц с алиасами: вручную и импорт из OpenStreetMap.
- **Sources:** вкл/выкл, интервал, последний запуск, последняя ошибка.
- **Listings:** журнал всех объявлений с решением, причиной отсева и полями от LLM.

## Архитектура

Пайплайн объявления: дешёвые проверки первыми, LLM только для прошедших.

```
SourceAdapter (Lun/Olx/DimRia) → RawListing DTO
→ SeenFilter        // dedup by source + external id
→ HardFilter        // structured fields only, unknown → pass with ❓
→ LlmEnricher       // fields + flags + location_id from the sector whitelist in the prompt
→ HardFilter again  // with enriched values
→ LocationMatcher   // location_id exists in whitelist; district only → 📍?
→ TelegramNotifier
```

Решение и причина отсева каждой стадии пишутся в журнал Listings.

### Структура

Стандартный Laravel 13, доменный код — по модулям в `app/`. Папка появляется вместе с первым классом в ней.

```
app/
  Sources/        # ListingSource, RawListing, адаптеры: Lun/, Olx/, DimRia/
  Pipeline/       # оркестратор и стадии: SeenFilter, Stages/ (HardFilter…)
  Enrichment/     # ListingEnricher, AnthropicListingEnricher
  Location/       # LocationMatcher, импорт улиц и ЖК из OpenStreetMap
  Currency/       # курс НБУ
  Telegram/       # TelegramNotifier, карточка объявления
  Models/  Filament/  Console/Commands/  Providers/
config/admin.php  # dev-админ для сидера
docker/           # php (Dockerfile, php.ini, crontab), postgres (init)
docs/             # ROADMAP, LOG, REQUIREMENTS, hosting.md, sources/
resources/views/telegram/   # тексты карточек и алертов
tests/Feature/  tests/Unit/  tests/Fixtures/<площадка>/
```

### Соглашения

- ООП, логика в классах, SOLID/KISS/YAGNI без оверинжиниринга. Современный PHP: строгая типизация, `readonly`, backed enum, DTO.
- Каждая площадка — класс, реализующий контракт `ListingSource`. Новая площадка добавляется без правок пайплайна.
- Внешние сервисы (площадки, LLM, Telegram, НБУ) живут за своими классами и интерфейсами. Тесты подменяют эти классы, а не HTTP.
- **Деньги:** `integer` в целых единицах + код валюты.
- **Время:** UTC в приложении и БД, колонки `timestampTz`. Модель с такими колонками задаёт `$dateFormat = 'Y-m-d H:i:sP'`, иначе Eloquent отбрасывает смещение и `23:55+03:00` записывается как 23:55 UTC.
- **Enum:** backed enum, в БД строка + cast.
- **Тексты для людей** (карточки, алерты) — в Blade-шаблонах `resources/views/telegram/`.
- **Язык:** код, комментарии и коммиты — на английском, документация — на русском.

### Тесты

- Pest. Перед коммитом тесты зелёные.
- Адаптеры тестируются на фикстурах реальных ответов площадок. Площадка сменила формат — обновляем фикстуру, тест показывает, что сломалось.
- Сеть в тестах закрыта: `Http::preventStrayRequests()`. LLM подменяется через `ListingEnricher`. Качество извлечения на реальном API проверяется отдельной artisan-командой.
