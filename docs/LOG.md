## Итог этапа 1

Headless-браузер не нужен: все три площадки отдают JSON по обычному HTTP.

| Площадка | Способ получения | Поля | Риски |
|---|---|---|---|
| ЛУН ([lun.md](sources/lun.md)) | `GET flatfy.ua/api/realties`, `sort=insert_time`, 24 на страницу | всё структурировано; координаты (нет у 15%), улица/ЖК в `geo_entities`, `autonomy_*` (генератор), ссылка на первоисточник | неофициальный API; с IP хостинга — 403 (Cloudflare), нужен UA-прокси; числа заполняет сам ЛУН и может ошибаться; поднятые объявления возвращаются наверх |
| OLX ([olx.md](sources/olx.md)) | `GET olx.ua/api/v1/offers/`, только HTTP/1.1, до 50 на страницу | `params` (комнаты, этаж, площадь, цена — всегда), `blackout_autonomy`, `layout`, `business` | неофициальный API; HTTP/2 → 403; с IP хостинга — 403 (CloudFront), нужен UA-прокси; координаты приблизительные (1–7 км); продвигаемые объявления среди обычных |
| DIM.RIA ([dimria.md](sources/dimria.md)) | `dom.ria.com/node/searchEngine/v2/` (id) + `/realty/data/{id}` (карточка) | точные координаты, улица и дом, метки `secondaryUtp`; заголовка нет | неофициальные эндпоинты (официальный API платный — запасной путь); N+1 запросов, первый запуск ~2400 карточек |

ЛУН не заменяет прямые источники: он находит 62% свежих объявлений OLX и 57% DIM.RIA с медианной задержкой 18–34 мин. Объявления OLX и DOM.RIA из ЛУН приходят второй карточкой — оставлено так (см. ROADMAP → «Потом»).

## Хронология

- 2026-10-04 — Пункт 14: адаптер OLX (`OlxSource`, `OlxListingMapper`): продвигаемые пропускаются, описание без HTML, точка на карте только при `radius ≤ 1`. Найдено: CloudFront OLX пускает по сочетанию TLS-отпечатка и версии HTTP — curl на macOS проходит только по HTTP/1.1, PHP на OpenSSL в контейнере — только по HTTP/2. Вывод разведки «только HTTP/1.1» исправлен; версия теперь в `SOURCES_HTTP_VERSION` (по умолчанию 2.0). Живой прогон из dev: 200 объявлений за 4,4 с, 13 прошли `HardFilter`.
- 2026-10-04 — Пункт 13: адаптер ЛУН (`LunSource`, `LunListingMapper`), поле `address` у объявлений (адрес одной строкой из полей площадки), `SourceHttp` — HTTP/1.1, таймаут и прокси по переключателю `use_proxy` у источника (`SOURCES_PROXY_URL`). Ответ не в JSON (проверка Cloudflare) роняет запуск, а не читается как «объявлений нет». Живой прогон из dev: 120 объявлений за 4,4 с, 10 прошли `HardFilter`, 108 отсеяны с причинами в журнале.
- 2026-10-04 — Итог этапа 3: тестовый источник проходит конвейер на реальном Postgres — новые объявления сохраняются, `HardFilter` пишет в журнал стадию и причину отсева, флаги ❓ и цена в гривне сохраняются, виденные пропускаются, запуск останавливается по виденным подряд и по времени (54 теста).
- 2026-10-04 — Пункт 12: таблица `sources` — вкл/выкл, интервал «от–до» (5–10 мин), `next_run_at`, последний запуск и успех, отчёт, последняя ошибка, ошибки подряд. `SourceRunner` ведёт учёт и выбирает следующий запуск случайно внутри интервала (джиттер). `sources:run-due` каждую минуту запускает один самый просроченный источник — так тик cron не выходит за лимит времени хостинга.
- 2026-10-04 — Пункт 11: `HardFilter` — комнаты, этаж и цена против Settings; неизвестное значение проходит с флагом (`flags`, enum `Flag`), если его переключатель ❓ включён. Цена переводится в гривну (`price_uah`) по курсу НБУ (`NbuExchangeRates`, кэш на сутки); НБУ недоступен — цена считается неизвестной. Доступ к `bank.gov.ua` с IP хостинга не проверен — проверим в пункте 28.
- 2026-10-04 — Решение пользователя: сектор определяется только по тексту. Координаты объявлений не используются, `GeoFilter` убран (заодно снята проблема приблизительных координат OLX). Whitelist улиц и ЖК наполняется вручную и импортом из OpenStreetMap по точке и радиусу из Settings. Сравнение делает LLM: whitelist с id передаётся в промпт, модель возвращает `location_id`, код его проверяет (было: fuzzy match в коде, алиасы в промпт не передаются). Флаг ⚠️ «карта против текста» больше не нужен.
- 2026-10-04 — Пункт 10: `RawListing`, `ListingSource` (ленивый `fetch()`, новые сверху), `SourceRegistry`, оркестратор `Pipeline` со стадиями `Stage` и `SeenFilter`, команда `sources:run {source}`. Изменён объём пунктов: `SeenFilter` сделан здесь, а не в 11; расписание с джиттером перенесено в 12 — ему нужно хранимое `next_run_at`.
