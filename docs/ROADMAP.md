# ROADMAP

Путь от пустой папки до бота, который работает на проде. Пункт отмечается `[x]`, когда он сделан и проверен (тесты зелёные или результат подтверждён). Принятые решения — в [CLAUDE.md](../CLAUDE.md) → «Стек и решения», где мы сейчас — в [LOG.md](LOG.md).

## Цель

Узнавать о каждой подходящей квартире в выбранном секторе Одессы в течение ~10 минут после публикации, со всех основных площадок, в одной Telegram-группе, без ручного мониторинга сайтов.

- [x] 34 Dev, тесты и CI на MariaDB: compose `mariadb:11.4` и `pdo_mysql`, миграции начисто (`dateTime` вместо `timestampTz`, `json` вместо `jsonb`), даты пишутся в UTC без смещения, поиск по алиасам без `::text ilike`, без схемы `rentradar` и `db:ensure-schema`, кодировка уникальных названий сектора; CI на `mariadb:11.4`; живой прогон площадок в dev
- [x] 35 Прод заново на MariaDB: база и пользователь в cPanel, PHP 8.4 с `pdo_mysql`, `.env`, снос приложения, деплой, «Первый запуск» по README, удаление базы PostgreSQL
