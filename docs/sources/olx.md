# OLX

Разведка 2026-10-04, пункт 02. Фикстура — [tests/Fixtures/olx/offers-odesa-rent-page-1.json](../../tests/Fixtures/olx/offers-odesa-rent-page-1.json).

## Итог

- **Берём OLX напрямую.** ЛУН пропускает около трети свежих объявлений OLX (см. «Покрытие в ЛУН»), а Otodim сейчас недоступен.
- Данные отдаёт публичный JSON API сайта, headless-браузер не нужен.
- **Важно: только HTTP/1.1.** CloudFront перед OLX отвечает 403 на запрос `curl` по HTTP/2 — даже с полным набором браузерных заголовков. С `--http1.1` и без особых заголовков → 200, ~0,4–0,6 с. HTTP-клиент Laravel (Guzzle) по умолчанию ходит по HTTP/1.1, но в адаптере версию задаём явно.

## Запрос

```
GET https://www.olx.ua/api/v1/offers/?offset=0&limit=50&category_id=1760&region_id=9&city_id=62&sort_by=created_at:desc&currency=UAH
```

| Параметр | Значение |
|---|---|
| `category_id` | `1760` — долгосрочная аренда квартир |
| `region_id`, `city_id` | `9`, `62` — Одеська область, Одеса (из `/api/v1/geo-encoder/location-autocomplete/?query=Одеса`) |
| `sort_by` | `created_at:desc` — на деле по времени последнего поднятия (`last_refresh_time`) |
| `offset`, `limit` | `limit` до 50, больше → 400 |
| `currency` | `UAH` — в какой валюте считать `converted_value` |

Ответ: `{data: [...], metadata: {total_elements, visible_total_count, promoted, source: {promoted, organic}}, links: {self, next, first}}`. `total_elements` ограничен 1000, по Одессе `visible_total_count` ≈ 6500. Объём — сотни новых объявлений в сутки.

**Продвигаемые объявления** вставляются сверх `limit` на фиксированные позиции (0–2, 13–15, 26–28…), их индексы — в `metadata.source.promoted`. Это старые объявления, они не новые. Условие «читать до первого уже виденного» проверяем только по `organic`.

## Поля объявления → `RawListing`

| Поле OLX | Что это | Заметки |
|---|---|---|
| `id` | id объявления | `external_id` |
| `url` | ссылка на объявление | содержит короткий id вида `ID11oxAU` — по нему же ЛУН ссылается на OLX |
| `title`, `description` | заголовок и описание | описание с HTML (`<br />`), перед LLM чистим |
| `created_time`, `last_refresh_time`, `pushup_time` | ISO 8601, **по Киеву (+03:00)** | переводим в UTC |
| `params[]` | `{key, name, type, value}` | см. ниже |
| `location.city`, `location.district` | город и район (`Приморський`) | район есть всегда |
| `map` | `{lat, lon, radius, show_detailed}` | **координаты приблизительные**, см. риски |
| `photos[].link` | `https://ireland.apollo.olxcdn.com:443/v1/files/{filename}/image;s={width}x{height}` | подставляем размер |
| `business` | `true` — бизнес-аккаунт | `false` → вероятно собственник (👤); в выборке 20% |
| `user.name`, `user.company_name` | автор | |

Ключи в `params` (заполненность в выборке из 325 объявлений Одессы):

| Ключ | Заполнен | Значение |
|---|---|---|
| `price` | 100% | `value.value` + `value.currency` (`UAH` 64%, `USD` 36%, `EUR` единицы); `value.converted_value` — уже в гривне |
| `number_of_rooms_string` | 100% | `odnokomnatnye`, `dvuhkomnatnye`, `trehkomnatnye`… |
| `floor`, `total_floors`, `total_area`, `kitchen_area` | 100% | строка-число в `value.key` |
| `blackout_autonomy` | 56% | список: `water_supply`, `heating`, `elevator`, `internet`, `backup_power_supply` — что работает при отключениях |
| `layout` | 68% | `separate` (раздельная), `adjacent_through` (смежная), `studio`, `free_layout`… |
| `heating` | 74% | `own_boiler-house`, `centralized`, `individual_gas`, `individual_electro`, `combined` |
| `pets`, `furnish`, `repair`, `commission`, `house_type` | частично | на будущее |

Комнаты, этаж и площадь на OLX — обязательные поля, но продавец может указать их неверно: например, евродвушку как 2 комнаты. Поэтому текст по-прежнему проверяет LLM.

## Покрытие в ЛУН

Проверка 2026-10-04 около 00:30 по Киеву. Взяты 81 новое объявление OLX по Одессе за последние 12 часов. Их искали по короткому id в `url_raw` на 60 страницах ЛУН — это 6 суток выдачи.

- В свежей выдаче ЛУН нашлось **50 из 81** (62%). Задержка ЛУН (`download_time` − `created_time` на OLX): минимум 8 мин, медиана 18 мин, максимум 2 ч 19 мин.
- **4** лежат глубоко в выдаче ЛУН со старым `insert_time`: ЛУН склеил их с более ранней копией объявления. Читая первые страницы ЛУН, их не увидеть.
- **27** (33%) в ЛУН нет совсем, хотя прошло от 1 до 9 часов.

## Otodim

Платформа OLX Group на данных OLX, бета с мая 2026. Адрес — `otodim.olx.ua` (`otodim.ua` не резолвится). На 2026-10-04 главная страница отвечает «Сторінку не знайдено». Даже если оживёт, она построена на тех же данных OLX, так что отдельный источник не нужен.

## Риски

- **Блокировка по отпечатку клиента.** Сейчас CloudFront режет HTTP/2-отпечаток `curl`, а HTTP/1.1 пропускает. Правило могут ужесточить — тогда алерт «3 ошибки подряд», а запасной вариант — ЛУН (около 2/3 объявлений OLX).
- **Зарубежный IP хостинга** (Hetzner) — проверяем в пункте 04.
- **Неофициальный API** без гарантий формата. Ловим через фикстуры и алерты.
- **Координаты приблизительные.** `map.radius` в км: `1` — точка с размытием около 1 км (в выборке 67%; у 218 объявлений всего 44 разные точки), `5` и `7` — фактически центр района (52 объявления с одной и той же точкой). Для `GeoFilter` это слабый сигнал.

## Что это меняет для других пунктов

- **11 `GeoFilter` и 18 `LocationMatcher`:** у OLX координаты с `radius > 1` считать отсутствующими, а с `radius = 1` — неточными (например, расширять радиус сектора на 1 км). Сектор для OLX будет определяться в основном по тексту. Решаем в пункте 11.
- **16–17 LLM:** `blackout_autonomy` даёт воду, тепло и лифт без LLM — так же, как `autonomy_*` у ЛУН. `layout` подсказывает раздельную или смежную планировку.
- **Дубли:** объявление OLX придёт дважды — из адаптера OLX и из ЛУН (`url_raw` с тем же `ID…`). Это разные `source`, поэтому придут две карточки — так решено 2026-10-04, правило дублей не меняем. Если станет мешать, можно сделать так: адаптер ЛУН пропускает площадки, которые мы читаем напрямую (`olx.ua`, потом `dom.ria.com`). Список задаётся в настройках источника, и если прямой адаптер сломается, площадку можно вернуть в ЛУН. Записано в ROADMAP → «Потом».
