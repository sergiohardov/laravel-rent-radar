# DIM.RIA (dom.ria.com)

Разведка 2026-10-04, пункт 03. Фикстуры — [tests/Fixtures/dimria/](../../tests/Fixtures/dimria/): страница поиска и три карточки (гривна и доллар, 1 и 2 комнаты).

## Итог

- **Читаем через внутренние эндпоинты сайта, без ключа** (решение 2026-10-04). Официальный API платный, ЛУН покрывает DIM.RIA лишь частично.
- Двухшаговая схема: поиск отдаёт id объявлений, затем карточка запрашивается по каждому новому id.
- `curl` без cookies и без особых заголовков → 200. Защиты вроде Cloudflare или CloudFront нет.

## Запросы

**Поиск** — id объявлений, новые сверху:

```
GET https://dom.ria.com/node/searchEngine/v2/?category=1&realty_type=2&operation=3&state_id=12&city_id=12&sort=created_at&page=0&limit=20
→ {"count": 2392, "items": [34999109, 34999047, ...]}
```

| Параметр | Значение |
|---|---|
| `category`, `realty_type` | `1`, `2` — квартиры |
| `operation` | `3` — долгосрочная аренда |
| `state_id`, `city_id` | `12`, `12` — Одесская область, Одесса |
| `sort` | `created_at` — новые сверху |
| `page`, `limit` | с 0 |

**Карточка** — по одному запросу на новый id (~4–6 КБ):

```
GET https://dom.ria.com/realty/data/{id}?lang_id=4
```

Не использовать `/v1/api/realty/getRealty/{id}`: он подробнее, но отдаёт `user_ip` автора объявления.

**Объём:** ~70 новых объявлений по Одессе в сутки (100 штук за ~33 часа). За запуск — один запрос поиска и несколько карточек.

## Поля карточки → `RawListing`

| Поле | Что это | Заметки |
|---|---|---|
| `realty_id` | id объявления | `external_id` |
| `beautiful_url` | slug | ссылка: `https://dom.ria.com/uk/{beautiful_url}` |
| `publishing_date` | `2026-10-03 23:55:16` | **время по Киеву без зоны**, переводим в UTC |
| `price`, `currency_type` | целое число, `грн` / `$` / `€` | в выборке 85% в гривне; `priceArr` — цена в `$`, `€`, `грн` |
| `rooms_count`, `floor`, `floors_count`, `total_square_meters` | числа | заполнены всегда |
| `latitude`, `longitude` | точные координаты | `radius_location`: `0` у 80% (точка дома), `1` у 17% |
| `street_name_uk`, `building_number_str` | улица и дом | номер дома пустой у 18% |
| `district_name_uk` | район или микрорайон | |
| `description_uk`, `description` | описание (укр, рус) | заголовка нет — вход для LLM только описание |
| `main_photo`, `photos{}` | путь вида `dom/photo/.../346345342.jpg` | `https://cdn.riastatic.com/photos/{путь без .jpg}fl.jpg`, превью — `b.webp` |
| `secondaryUtp[]` | метки продавца | «Укриття в будинку», «Територія охороняється», «Світло 24/7» — подсказки для 🔒 и ⚡ |
| `realtorVerified`, `agencyVerified` | проверенный риелтор или агентство | признака «собственник» нет, 👤 определяет LLM |
| `withAnimal` | можно с животными | на будущее |

Площади кухни в этом эндпоинте нет. Если понадобится для требования «кухня не маленькая», её можно брать из HTML страницы каталога (`__INITIAL_STATE__.catalog.realtyForCatalog[].kitchen_square_meters`) или искать в тексте.

Проверка 2026-10-04 около 00:40 по Киеву, по той же методике, что для OLX. Взяты 99 объявлений DOM.RIA старше часа, их искали по id в `url_raw` на 40 страницах ЛУН (~3,5 суток).

## Официальный API

`developers.ria.com`: `GET /dom/search?api_key=…` (id) и `GET /dom/info/{id}?api_key=…` (карточка без телефона) — та же схема, что у сайта. Тип «Фріміум»:

- бесплатный пакет — 1000 запросов, не больше 30 в час;
- платный — 20 000 запросов за 420–500 грн в месяц.

Нам нужно ~220–360 запросов в сутки (поиск раз в 5–10 минут плюс ~70 карточек), бесплатного пакета хватит на 3–4 дня. Это запасной путь, если эндпоинты сайта закроют.

## Риски

- **Неофициальные эндпоинты** могут поменяться или закрыться. Ловим через фикстуры и алерт «3 ошибки подряд», запасной путь — официальный API.
- **Зарубежный IP хостинга** (Hetzner) — проверяем в пункте 04.
- **N+1 запросов:** при первом запуске нужно забрать все текущие совпадения, а это около 2400 карточек. Это не укладывается в один запуск на 60 с, поэтому первый проход делим на несколько запусков или сначала берём только свежие объявления. Решаем в пункте 15.
